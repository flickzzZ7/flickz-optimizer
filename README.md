# Flickz Optimizer

A modern, animated, **hardware-aware** optimizer for Windows 10/11 (x64).

**[⬇ Download the latest Setup.exe](https://github.com/flickzzZ7/flickz-optimizer/releases/latest/download/FlickzOptimizer-win-Setup.exe)** · [All releases](https://github.com/flickzzZ7/flickz-optimizer/releases)

---

## English

Flickz Optimizer detects your PC (CPU, GPU, RAM, disks, monitors) and recommends tweaks that make sense for *your* hardware. Every change is backed up and can be restored. The app updates itself from these GitHub Releases.

### Install
1. Download `FlickzOptimizer-win-Setup.exe` from the [latest release](https://github.com/flickzzZ7/flickz-optimizer/releases/latest).
2. Run the installer. Windows SmartScreen may warn because the build is not code-signed: choose **More info → Run anyway**.
3. Accept the license agreement on first launch. The app requests administrator rights (UAC) to apply system tweaks.

### Features
- Dashboard with optimization score and live CPU / RAM / GPU monitor
- Performance, graphics, startup/services, cleanup and per-game tweaks
- One-click profiles: Gaming / Balanced / Quiet
- Restore point + backup of every change, one-click Restore
- English and Italian UI
- Automatic updates (Velopack)

### Disclaimer
This software changes Windows settings, the registry, services and scheduled tasks. It creates a restore point and backups, but **you use it at your own risk**. The copyright holder is not responsible for any damage, data loss or instability. Always keep your own backups.

Flickz Optimizer rileva il tuo PC (CPU, GPU, RAM, dischi, monitor) e consiglia solo le ottimizzazioni adatte al *tuo* hardware. Ogni modifica viene salvata in un backup e si può annullare. L'app si aggiorna da sola da queste GitHub Releases.

### Installazione
1. Scarica `FlickzOptimizer-win-Setup.exe` dall'[ultima release](https://github.com/flickzzZ7/flickz-optimizer/releases/latest).
2. Avvia l'installer. Windows SmartScreen potrebbe avvisare perché la build non è firmata: scegli **Ulteriori informazioni → Esegui comunque**.
3. Al primo avvio accetta il contratto di licenza. L'app chiede i permessi di amministratore (UAC) per applicare le modifiche di sistema.

### Funzioni
- Dashboard con punteggio di ottimizzazione e monitor live di CPU / RAM / GPU
- Prestazioni, grafica, avvio/servizi, pulizia e ottimizzazioni per gioco
- Profili con un clic: Gaming / Bilanciato / Silenzioso
- Punto di ripristino + backup di ogni modifica, Ripristina con un clic
- Interfaccia in inglese e italiano
- Aggiornamenti automatici (Velopack)
